# Kamus Serapan Bahasa Indonesia dari Bahasa Arab

Folder ini menampung proyek kamus serapan yang berisi kata-kata bahasa Indonesia yang berasal dari bahasa Arab.

## Deskripsi Proyek

Proyek ini bertujuan untuk:
- Mengumpulkan daftar kata serapan bahasa Indonesia dari bahasa Arab
- Menyediakan terjemahan dan penjelasan makna
- Mendokumentasikan etimologi dan asal-usul kata
- Memperkaya referensi linguistik bahasa Indonesia

## Struktur Folder

```
kamus-serapan/
├── data/          # File data kamus (JSON, CSV, dll)
├── docs/          # Dokumentasi dan panduan
└── scripts/       # Script untuk pengolahan data (jika diperlukan)
```

## Kontribusi

Silakan berkontribusi dengan menambahkan data kata serapan baru atau memperbaiki dokumentasi yang sudah ada.
